《极速先锋：工业传奇》12周详细执行计划 (180小时版)

说明： 假设每天投入 2 小时，每周共 14 小时。

第一阶段：骨架构建与底层逻辑 (Month 1)

第 1 周：项目初始化与静态数据

周一： Cocos Creator 项目环境搭建，创建文件夹结构（Scripts, Prefabs, Res, Data）。

周二： 设计核心 JSON 数据结构：Cars.json (初始车型数据) 和 Parts.json (基础零件)。

周三： 设计 Employees.json (随机池属性) 和 TechTree.json (技术节点逻辑)。

周四： 编写 DataManager.ts 单例类，实现 JSON 数据的异步加载与全局访问。

周五： 搭建“主界面 (Main Hub)”基础 UI 框架（顶部资源条、侧边导航栏）。

周六： 编写场景切换脚本，实现主界面、实验室、工厂之间的无缝跳转。

周日： 本周回顾： 检查所有数据是否能正常读入并在控制台打印，备份代码。

第 2 周：人才系统原型

周一： 制作“员工头像卡片” Prefab。

周二： 编写“人才市场”逻辑：实现随机生成 3-5 名工程师。

周三： 实现“招聘”功能：判断资金是否足够，扣费并加入“已拥有员工”列表。

周四： 编写“时间/回合系统”：点击“下一周”，资金自动扣除工资，员工体力恢复。

周五： 制作“已雇佣员工列表” UI，展示员工数值（能力、经验、忠诚度）。

周六： 实现员工头像的点击弹出框，显示员工详细生平/技能描述。

周日： 数值调试： 调整初始工资与招聘费用的平衡。

第 3 周：技术树（研发）逻辑

周一： 实验室 (Scene 2) 基础 UI 搭建（滚动视图展示技术节点）。

周二： 实现技术节点的连接线逻辑（判断前置条件是否解锁）。

周三： 编写技术解锁功能：消耗研发点，进度条开始运行。

周四： 实现“研发点”获取逻辑（基于已拥有员工的能力值产出）。

周五： 编写技术解锁后的“效果应用”逻辑（如：解锁新引擎零件）。

周六： 完善技术树视觉效果（已解锁变绿、未解锁灰色）。

周日： 整合测试： 尝试招聘高能力员工，观察研发点产出速度是否符合预期。

第 4 周：车型立项与设计 UI

周一： 制作“新项目开启”弹窗：输入车型名称，选择目标定位（SUV/轿车等）。

周二： 编写立项后的数据初始化：创建一个空的 CurrentProject 对象。

周三： 制作零件选择界面：根据已解锁技术，展示可用的引擎、底盘列表。

周四： 实现零件选择的互相排斥逻辑（如：纯电底盘不能配燃油引擎）。

周五： 编写初步的“成本预估”计算器，实时更新项目总造价。

周六： 整合设计阶段的 UI 动效（点击安装零件时的音效和微动）。

周日： 阶段总结： 跑通“立项 -> 选件”流程。

第二阶段：系统集成与交互增强 (Month 2)

第 5 周：研发点分配系统 (R&D Slider)

周一至周三： 实现三个核心研发滑块（外观、工程、软件）的 UI 与逻辑。

周四： 编写“投入员工”逻辑：选择哪些员工参与本项目。

周五： 计算项目研发总时长：TotalTime = Difficulty / TeamAbility。

周末： 实现研发过程中的进度条更新，以及员工体力随时间扣除。

第 6 周：核心评分算法与媒体评价

周一至周三： 编写 ReviewSystem.ts：根据车型参数（性能、科技、价格）生成 1-10 分。

周四： 设计 5 个不同倾向的媒体对象及其评价模版。

周五： 实现评分后的 UI 表现：媒体 Logo 闪烁，弹出评分和评语。

周末： 调优评分公式：确保不会轻易出现满分或零分。

第 7 周：发布会 Q&A 与市场模拟

周一： 发布会场景 UI 搭建（讲台、媒体席）。

周二： 编写“媒体提问”数据库（约 20 个问题及其答案权重）。

周三： 实现问答交互：倒计时选择，好感度增减动效。

周四： 编写销量计算引擎：Sales = BaseDemand * Rating * QABonus。

周五： 实现“首周财报”结算界面。

周末： 增加发布会中的闪光灯粒子效果，提升代入感。

第 8 周：第一个完整 Beta 闭环

周一至周五： 全力修复前 7 周整合时产生的 Bug。

周末： 游玩测试： 自己完整玩 3 遍流程，确保没有卡死或资金无法循环的情况。

第三阶段：竞争对手与体验优化 (Month 3)

第 9 周：AI 竞争对手系统

周一： 编写 AI 公司的基础类，设定 3 个不同等级的 AI 对手。

周二： 模拟 AI 发布频率：每隔 X 月，AI 发布一款随机性能的竞品。

周三： 实现“市场份额”算法：根据玩家与 AI 车型的综合竞争力瓜分市场。

周四至周五： 编写“排行榜”UI：显示公司排名、市值、市场占有率。

周末： 调校 AI 的成长速度，确保玩家感到压力但不会被瞬间击垮。

第 10 周：美术迭代与动效 (Tween)

周一至周三： 使用 cc.tween 为所有数值变化增加平滑滚动效果（如钱数增长）。

周四： 优化所有人物头像和车辆占位图，提升视觉一致性。

周五： 增加场景背景的动态效果（如办公室窗外白昼更替）。

周末： 整合背景音乐 (BGM) 和核心操作音效。

第 11 周：平衡性与随机事件

周一至周三： 编写“随机事件系统”：如“能源价格暴涨”、“某员工被挖角”。

周四至周五： 填补 50 条以上的随机事件 JSON 数据，并关联后果逻辑。

周末： 最后一次数值平衡测试：针对后期资金过剩问题进行通胀调配。

第 12 周：收尾与导出

周一： 实现 LocalStorage 存档/读档功能。

周二： 增加设置面板（音量调节、清除存档、语言）。

周三： 处理游戏引导 (Tutorial)：第一次进入时提示如何操作。

周四： 进行多分辨率适配检查（手机 vs 电脑浏览器）。

周五： 导出 H5 预览版并邀请朋友试玩，收集反馈。

周末： 最终 Bug 修复，正式打包发布。
