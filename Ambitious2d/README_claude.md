# Ambitious2d - 商业模拟经营游戏

## 项目介绍

**Ambitious2d** 是一款基于 **Cocos Creator 3.8.4** 开发的 2D 商业模拟经营游戏。在游戏中，玩家将扮演一位店铺经营者，从零开始打造自己的商业帝国。

玩家可以：
- 开设多种类型的店铺（服装店、花店、书店、电器店）
- 雇佣和管理员工
- 进货、摆货、定价
- 接待顾客、完成交易
- 升级店铺、解锁更多功能

## 技术栈

- **引擎**: Cocos Creator 3.8.4
- **语言**: TypeScript
- **平台**: Web / 跨平台

## 已实现功能

- [x] 玩家数据管理（名称、金钱、等级）
- [x] 本地数据持久化（localStorage）
- [x] 游戏内时间系统（支持时间流逝）
- [x] 跨场景数据共享

### 2. 店铺系统
- [x] 多店铺管理（支持服装店、花店、书店、电器店）
- [x] 货架系统（商品上架、库存显示）
- [x] 店铺信息展示（名称、类型、租金）

- [x] 商品类型定义（服装、鲜花、书籍、电子产品）

### 4. 顾客系统
- [x] 顾客自动生成
- [x] 顾客随机外观（多角色图片）
- [x] 顾客随机行为模拟
- [x] 根据店铺热度调整顾客生成频率

### 5. 仓库系统
- [x] 仓库货物存储
- [x] 仓库货物显示
- [x] 货物数量管理

### 6. 员工系统
- [x] 员工数据结构定义（ID、姓名、年龄、技能、薪资、忠诚度）
- [x] 员工招聘界面
- [x] 员工属性管理

- [x] 天赋系统（5种天赋）

  - 人事专家: 员工忠诚度+10%

### 8. 商业链条
- [x] 批发商场景（WholeSalerScene）
- [x] 经销商场景（DealerScene）
- [x] 人力资源场景（HRScene）

## 主要脚本说明

| 脚本 | 功能说明 |
|------|----------|
| `TopManager.ts` | 全局管理器，负责游戏核心数据管理、场景切换、时间系统 |
| `GameManger.ts` | 玩家数据管理（金钱、名称、商店数量） |
| `DataCollection.ts` | 数据类型定义（玩家、店铺、商品、员工等） |
| `StoreScript.ts` | 商店场景核心逻辑（货架生成、顾客生成） |
| `CustomerScript.ts` | 顾客行为逻辑 |
| `ShelveScript.ts` | 货架显示逻辑 |
| `Createnew.ts` | 仓库货物显示 |

## 如何运行

1. 安装 Cocos Creator 3.8.4
2. 打开项目文件夹 `Ambitious2d`
3. 在 Cocos Creator 中打开项目
4. 点击运行按钮启动游戏

## 游戏流程（预期）

1. **开始游戏** → 创建角色、输入名字
2. **天赋选择** → 选择初始天赋
3. **地图选择** → 选择要去的地方
4. **店铺经营** → 管理店铺、摆货、接待顾客
5. **仓库管理** → 查看库存、补充货物
6. **招聘员工** → 雇佣员工帮助经营
7. **扩展业务** → 开设新店铺、解锁更多商品
