### 特性效果计算规则

```
实际效果 = 特性基础值 × (stackable ? 叠加次数 : 1)
```

### 特性抽取与效果计算（设计说明）

```typescript
/**
 * 根据稀有度权重随机抽取指定数量的特性
 * @param count 抽取数量
 * @param excludeIds 排除的特性ID列表
 * @returns 抽取到的特性模板数组
 */
export function drawRandomTraits(count: number, excludeIds: string[] = []): ITraitTemplate[] {
  const pool = TRAIT_POOL.filter(t => !excludeIds.includes(t.id));
  const result: ITraitTemplate[] = [];
  const usedIds: string[] = [...excludeIds];

  for (let i = 0; i < count && pool.length > 0; i++) {
    const rolled = rollTraitByRarity(pool, usedIds);
    if (rolled) {
      result.push(rolled);
      usedIds.push(rolled.id);
    }
  }
  return result;
}

/**
 * 按稀有度权重随机抽取一个特性
 */
function rollTraitByRarity(pool: ITraitTemplate[], excludeIds: string[]): ITraitTemplate | null {
  const available = pool.filter(t => !excludeIds.includes(t.id));
  if (available.length === 0) return null;

  // 计算总权重
  const totalWeight = available.reduce((sum, t) => sum + TRAIT_RARITY_WEIGHTS[t.rarity], 0);

  // 随机roll
  let roll = Math.random() * totalWeight;
  for (const trait of available) {
    roll -= TRAIT_RARITY_WEIGHTS[trait.rarity];
    if (roll <= 0) return trait;
  }
  return available[available.length - 1];  // 兜底
}

/**
 * 根据特性ID获取特性模板
 */
export function getTraitTemplate(id: string): ITraitTemplate | undefined {
  return TRAIT_POOL.find(t => t.id === id);
}

/**
 * 计算特性效果对数值的影响
 * @param baseValue 基础数值
 * @param traits 已激活的特性ID列表
 * @param effectType 效果类型
 * @returns 应用特性加成后的数值
 */
export function applyTraitEffect(baseValue: number, traits: string[], effectType: TraitEffectType): number {
  let result = baseValue;
  for (const traitId of traits) {
    const trait = getTraitTemplate(traitId);
    if (!trait || trait.effectType !== effectType) continue;
    if (trait.effectType === 'money_add' || trait.effectType === 'warehouse_bonus') {
      result += trait.effectValue;   // 固定值加成
    } else {
      result *= (1 + trait.effectValue);  // 百分比加成
    }
  }
  return result;
}
```

### 新建角色流程（特性选择）

```
1. 玩家输入姓名
2. 系统从候选池中随机抽取3个不同特性（按稀有度权重）
3. 展示3个特性卡片，玩家选择1个
4. 选中特性写入 player.traits，pendingTraitChoices 清空
5. 特性效果在 IGameState 初始化时生效
```

## 三、公式汇总

### 1. 店铺日均人流量
```
日均人流量 = floor(baseFootTraffic(位置) × trafficMultiplier(面积)) × (1 + footTrafficBonus(等级))
```

### 2. 员工对店铺的收益加成（运行时计算）
```
revenueBonus = levels[currentRole] × 系数
```

### 3. 贷款每周利息
```
周日结算利息 = loanAmount × loanInterestRate
```

### 4. 仓库已用体积（运行时计算）
```
warehouseUsed = Σ(inventory[itemId] × item.volume)
```

### 5. 升级后仓库容量（含住宅加成）
```
实际仓库容量 = warehouseCapacity × storageBonus(如有)
```

### 6. 升级后员工上限（含住宅加成）
```
实际员工上限 = maxEmployees + staffDormBonus(如有)
```

### 7. 顾客本次购物满意度（运行时计算，结账后写入 ICustomerData.shoppingSatisfaction）
```
shoppingSatisfaction = (商品可得性得分 × 0.5) + (排队等待得分 × 0.3) + (环境整洁度得分 × 0.2)
```

### 8. 店铺每日评分（指数移动平均，每日结算时更新）
```
今日评分均值 = floor(当日所有离店顾客 shoppingSatisfaction 之和 ÷ 顾客数)
rating = floor(rating × 0.7 + 今日评分均值 × 0.3)
rating = clamp(rating, 0, 100)
```
- 新店无历史评分时，直接以今日均值作为初始 rating
- rating 范围 [0, 100]，超出上限时取边界值
- **UI 显示换算**：displayRating = (rating / 100) × 5.0，保留一位小数，如 "⭐ 4.5"

### 9. 期望薪资（运行时计算）
```
avgSkills = floor((skills.cashier + skills.stocker + skills.cleaner) / 3)
expectedSalary = floor(initialSalary × (1 + avgSkills / 200))
```

### 10. 每周离职概率（每周一计算）
```
if (dailySalary >= expectedSalary) {
  quitProbability = 0.001;  // 满足期望时，固定为最低 0.1%，即使薪资远超期望也不再降
} else {
  shortfall = expectedSalary - dailySalary;
  quitProbability = min(baseQuitProbability + shortfall × 0.0005, 0.5);
}
```

### 11. 收银时间
```
checkoutTime = floor(baseCheckoutTime / (1 + cashierSkill × 0.02))
```

### 12. 培训技能提升
```
skillGain = random(trainingSkillGainMin, trainingSkillGainMax)
// 培训完成后：skills[trainingRole] += skillGain
```

### 1. 订单数据 `IOrder`

```typescript
type OrderStatus = 'pending' | 'delivered' | 'overflow' | 'cancelled';

interface IOrder {
  id: string;               // 订单ID

  // 内容（下单时确定）
  items: ICartItem[];       // 订单明细
  totalCost: number;        // 订单总价
  totalVolume: number;      // 订单总体积

  // 时间
  orderDay: number;         // 下单日（第N天）
  deliveryDay: number;      // 送达日（通常是下周一）

  // 状态
  status: OrderStatus;

  // 送达后填写
  deliveredItems: ICartItem[];   // 实际入库的物品
  lostItems: ICartItem[];        // 被盗的物品（溢出部分，付过款但无法入库）
  actualCost: number;             // 实际扣款金额
}
```

### 2. 订单流程

```
筹备期：玩家将商品加入购物车
        ↓
玩家点击"确认下单" → 生成 IOrder，status=pending，购物车清空
        ↓
周一批发商送货：
  ① 计算仓库剩余容量
  ② 扣款 = 实际入库数量 / 订单总量 × totalCost（按比例扣）
  ③ 入库：能放进仓库的物品写入 deliveredItems，加入 inventory
  ④ 溢出：付过款但放不下的 → 写入 lostItems，货物消失（被盗）
        ↓
订单状态更新为 delivered 或 overflow，存入 orderHistory
```

### 3. 订单送达时扣款公式

```
可入库体积 = min(订单总体积, 仓库剩余容量)
实际扣款 = floor(可入库体积 / 订单总体积 × totalCost)
溢出损失 = totalCost - actualCost（买货钱白付了）
```

### 4. 多订单并行

玩家可同时拥有多笔 pending 状态的订单，每笔独立送达、独立结算，互不影响。
