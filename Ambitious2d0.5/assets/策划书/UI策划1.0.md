> 最后更新：2026-07-02

## 一、UI 系统架构

### 1.1 界面层级树

```
游戏根节点
├── StartScene（启动场景）
│   ├── [Logo 展示 + 标题]
│   └── 主菜单面板
│       ├── [新游戏] 按钮
│       ├── [继续游戏] 按钮（存档存在时显示）
│       ├── [成就] 按钮
│       └── [退出游戏] 按钮
│   └── 新游戏弹窗（点击新游戏时显示，两阶段）
│       ├── 阶段1: 姓名输入
│       │   ├── 玩家姓名输入框（max 8字）
│       │   └── [下一步] 按钮
│       └── 阶段2: 特性选择
│           ├── 随机特性卡片 x3
│           ├── [随机] [确认] 按钮
│           └── [成就] 弹窗（点击成就时显示）
│
└── MainScene（营业场景，HTML/CSS 实现）
    ├── 场景背景层（scene-bg）
    ├── 游戏世界层（game-world，Tilemap 占位）
    │
    ├── homeHUD（回家状态，默认显示）
    │   ├── 顶栏: [←返回] [Day X - 周X ☀️] [玩家名+特性] [$XXX] [仓库条] [去店铺]
    │   ├── Tab 内容面板（进货市场/账单复盘/人才市场/产业总览，占位中）
    │   ├── 快捷功能栏: [开设新店] [员工管理] [房屋信息]
    │   └── TabBar: [进货市场] [账单复盘] [人才市场] [产业总览]
    │
    ├── storeHUD（店铺状态，点击"去店铺"后显示）
    │   ├── 顶栏: [08:00] [☀️] [店名+类型居中] [$XXX] [仓库条] [⭐评分]
    │   ├── 货架网格区（5列，根据面积显示 N 个货架格子）
    │   │   ├── 空货架: 虚线框 + +
    │   │   └── 有货架: 商品图标 + 名称 + 售价
    │   └── 底栏: [1x][2x][3x] [仓库剩余: XX] [回家]
    │
    └── 共用弹窗
        ├── 开设新店弹窗（4步向导: 选类型+店名 → 选面积 → 选位置 → 确认开设）
        ├── 货架商品选择弹窗（点击货架后显示，类型对应商品列表）
        ├── 成就弹窗
        └── 退出确认弹窗
```

### 1.2 设计规范

**美学风格**：复古像素风 + 温馨小店氛围

**配色方案**：
- 主色：`#2D1B0E`（深木棕，背景）
- 次色：`#F5E6D3`（米黄，主文字/按钮）
- 点缀：`#D4A84B`（金币黄，强调/图标）
- 辅助：`#8B6914`（深金，边框）
- 警告：`#C75D5D`（淡红，警示）
- 成功：`#5D9B5D`（淡绿，确认）

**字体**：
- 标题：`Press Start 2P`（像素风）
- 正文：`Noto Sans SC`（中文支持）

## 二、StartScene（启动场景）

### 2.1 整体视觉

**场景概述**：

启动场景是玩家进入游戏的第一触点，承担品牌传达和情感铺垫的作用。整体氛围：温馨的夜晚小店灯火，像素风但不粗糙，有手工感的拙朴感。

**视觉参考**：
- 开罗游戏标题画面（像素 + 暖调）
- 深夜食堂的灯光感
- 8-bit 复古游戏的质感

### 2.2 背景层 (BackgroundLayer)

**视觉描述**：
- 纯色背景 `#2D1B0E`（深木棕）
- 背景上有极淡的瓦片纹理叠加（5% 透明度，模拟旧纸质感）
- 可选：画面顶部和底部有微弱的渐变光晕（模拟室内灯光）

**技术实现**：
- 全屏 Sprite，sizeMode = RAW
- 纹理可为空，使用 SolidColor Material
- 纹理叠加：平铺的 64×64 像素纹理，opacity = 12

### 2.5 菜单面板 (MenuPanel)

**视觉描述**：

```
垂直排列的三个按钮，按钮之间间距相等

按钮尺寸（主按钮）：
┌────────────────────────────────┐
│                                │
│         按钮文字                │
│                                │
└────────────────────────────────┘
宽度: 240px
高度: 56px

字体: Press Start 2P, 14px

```

**四个按钮**：

| 按钮 | 文字 | 优先级 | 位置 |
|:-----|:-----|:-------|:-----|
| 新游戏 | "新游戏" | 主按钮（最亮）| 第一个 |
| 继续游戏 | "继续游戏" | 次按钮（存档存在时显示）| 第二个 |
| 成就 | "成就" | 次按钮 | 第三个 |
| 退出游戏 | "退出游戏" | 次按钮（最暗）| 第四个 |

**继续游戏按钮特殊规则**：
- 初始：`active = false`（不显示）
- 检测到存档：fade in 显示
- 文字下方可显示最后存档时间（小字，`#B8A080`）

```
继续游戏
2026-06-06 14:30        ← 小字，次要信息
```

**成就按钮**：
- 不需要存档检测，任何时候都显示
- 点击后打开成就面板（Overlay）

**退出游戏按钮**：
- 不需要存档检测，任何时候都显示
- 点击后弹出确认对话框

### 2.6 菜单按钮详细设计

#### 2.6.1 按钮尺寸与间距

```
按钮参数：
- 宽度：240px
- 高度：56px
- 间距：12px（按钮与按钮之间，缩短以容纳4个按钮）
- 圆角：4px（轻微圆角，保持像素感）

菜单面板内边距：
- 水平：0px（按钮本身有弹性）
- 垂直：按钮高度×4 + 间距×3 = 56×4 + 12×3 = 260px
```

#### 2.6.2 按钮背景

```
正常状态（Normal）：
┌────────────────────────────────┐
│ border: 2px solid #8B6914      │
│ background: #3D2B1E             │
│ border-radius: 4px              │
└────────────────────────────────┘

像素风边框效果：
- 使用 9-patch 或 CSS border-image 模拟像素边框
- 边框角用 2×2 像素块
```

#### 2.6.3 按钮文字

```
字体：Press Start 2P
字号：14px
颜色：#F5E6D3
字间距：2px
水平居中
垂直居中

文字效果：
- 无描边
- 无阴影
- 纯色
```

#### 2.6.4 按钮状态

**Hover（悬停）**：

| 属性 | 变化 |
|:-----|:-----|
| 背景色 | #3D2B1E → #4D3B2E |
| 边框色 | #8B6914 → #D4A84B（金色高亮）|
| 缩放 | scale(1.0) → scale(1.05) |
| 光标 | default → pointer |
| 过渡 | 150ms ease-out |

**按下（Pressed）**：

| 属性 | 变化 |
|:-----|:-----|
| 缩放 | scale(1.0) → scale(0.95) |
| 边框色 | #D4A84B（保持高亮）|
| 过渡 | 100ms ease-in |

**释放（Release）**：

| 属性 | 变化 |
|:-----|:-----|
| 缩放 | scale(0.95) → scale(1.05) → scale(1.0) |
| 时长 | 100ms + 100ms |

**禁用（Disabled）**：

| 属性 | 变化 |
|:-----|:-----|
| 透明度 | 100% → 50% |
| 灰度 | grayscale(0) → grayscale(1) |
| 光标 | pointer → not-allowed |
| 边框色 | #8B6914 → #5B4B3B |

#### 2.6.5 主按钮 vs 次按钮

**"新游戏"**：
- 完全不透明
- 边框金色时更亮
- 可称为"主按钮"

**"继续游戏" / "成就"**：
- 边框保持 `#8B6914`（不变化）
- 整体亮度略低
- 可称为"次按钮"

#### 2.6.6 按钮点击反馈时序

```
用户点击（0ms）
    ↓
按钮 scale → 0.95（100ms, ease-in）
    ↓
按钮 scale → 1.05（100ms, ease-out）
    ↓
按钮 scale → 1.0（100ms, ease-out）
    ↓
触发按钮回调（300ms）
```

### 2.8 入场动画时序

**场景加载完成 → 动画开始**：

```
═══════════════════════════════════════
0ms
│
├─ 背景层 fade in
│   └─ opacity 0 → 1 (300ms, linear)
│

│
├─ Logo 区域出现
│   ├─ Y 轴：从 (logoY - 30px) → logoY
│   ├─ opacity: 0 → 1
│   ├─ scale: 0.95 → 1.0
│   └─ 时长：1200ms，缓动：backOut
│
│       ├─ 装饰线 fade in (Logo 动画结束后 100ms)
│       └─ 装饰线 opacity 0 → 1 (300ms)
│
600ms ─────────────────────────────────
│
├─ 主标题淡入
│   ├─ opacity: 0 → 1
│   └─ 时长：800ms，缓动：ease-out
│
│       ├─ 副标题淡入（主标题后 100ms）
│       └─ opacity: 0 → 1 (800ms)
│
900ms ─────────────────────────────────
│
├─ 菜单面板淡入
│   ├─ opacity: 0 → 1

│

│
├─ [新游戏] 按钮淡入 (Y: +20px → 0)

│
1250ms ─────────────────────────────────
│
├─ [继续游戏] 按钮淡入 (Y: +20px → 0)

1400ms ─────────────────────────────────

**Idle 状态动画（循环）**：

```

- 点击"确认"锁定选择

### 2.11 存档检测逻辑

```
StartScene.onLoad()
    ↓
SaveManager.hasSaveData()
    ↓
    ├─ true：
    │   ├─ 显示 [继续游戏] 按钮
    │   ├─ 获取最后存档时间
    │   └─ 格式化显示："2026-06-06 14:30"
    │
    └─ false：
        └─ 不显示 [继续游戏] 按钮
```

**存档数据结构**（SaveManager 保存的）：

```typescript
interface GameSaveData {
  version: string;        // "1.0.0"
  savedAt: number;        // timestamp
  lastPlayedAt: number;  // timestamp
  playTime: number;      // 秒
  dayReached: number;    // 到达的天数
  stateChecksum: number; // 存档状态校验和（CRC32）
}

/**
 * 存档数据结构说明：
 *
 * 存档文件 = {
 *   meta: GameSaveData,     // 存档元数据
 *   state: IGameState      // 完整游戏状态（单独 JSON 存储）
 * }
 *
 * 存档校验：
 * - 保存时：计算 IGameState 的 CRC32 校验和，存入 stateChecksum
 * - 读取时：重新计算校验和，与 stateChecksum 对比，不一致则提示存档损坏
 *
 * 最大存档大小：1MB（超出时提示存档过大）
 */
